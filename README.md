# nicolasventures.com

This repo is the **live** source of nicolasventures.com, served by GitHub Pages.

- **Domain:** nicolasventures.com (configured via `CNAME`)
- **Deploy:** push to `main` → GitHub Pages rebuilds in ~1 min. No build step, no CI.
- **Content:** plain HTML/CSS. Edit `index.html` directly.

## Layout

- `index.html` — the homepage (single-page site)
- `flux-overview/` — secondary page
- `CNAME` — domain binding

## Heads up

There is a separate Hugo repo named `nicolasventureswebsite02` — **that is not the live site.** Do not edit it expecting changes to appear on nicolasventures.com.
